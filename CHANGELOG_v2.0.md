# AETHER v2.0 — AutoTrader (Groww Edition)
- Added authenticated, per-user ₹50,000 paper accounts.
- Added CASH and FNO paper positions, order blotter, estimated costs and slippage.
- Added server-side 1% per-trade risk, 2% daily realized-loss lockout, 25% single-position and 100% gross-exposure limits.
- Added long-only paper execution, position close validation and duplicate-order protection.
- Added rule-based research signal evaluation for trend, swing trend, breakout and mean reversion.
- Added optional Groww SDK read-only LTP adapter.
- Added Android-first AutoTrader PWA workspace.
- Explicitly did not add broker order placement; real execution remains disabled.
